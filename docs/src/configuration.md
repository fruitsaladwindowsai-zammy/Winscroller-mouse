# Configuration Reference

Winscroller Mouse persists settings atomically to `%APPDATA%\WinscrollerMouse\settings.json`.

See the complete key-by-key schema in the repository's [`CONFIGURATION.md`](https://github.com/fruitsaladwindowsai-zammy/Winscroller-Mouse/blob/main/CONFIGURATION.md) and the validated default template in [`winscroller-mouse.example.json`](https://github.com/fruitsaladwindowsai-zammy/Winscroller-Mouse/blob/main/winscroller-mouse.example.json).

## Key Categories
- **Trails**: `trail`, `trailLife`, `trailSize`, `trailStrength`
- **Halos**: `halo`, `haloSize`, `haloStrength`, `haloShow`
- **Colors & Panel**: `colorMode`, `customColor`, `customColor2`, `panelColor`, `panelBg`, `panelFg`, `panelCustomColor`, `panelText`, `panelFrame`, `panelTint`, `panelOpacity`
- **Cursor Forge**: `pointerTheme`, `pointerSize`, `cursorShape`, `cursorTilt`, `cursorRound`, `cursorSurface`, `cursorFill`, `cursorLine`, `cursorOrnament`, `cursorShadow`, `cursorHand`, `cursorBeam`, `cursorBusy`, `cursorBusySpeed`
- **Hiding & Find**: `hideAfter`, `hideTyping`, `shake`, `shakeSensitivity`, `findSize`
- **Behavior**: `enabled`, `fullscreen`, `fps`, `startLook`, `startWithWindows`
