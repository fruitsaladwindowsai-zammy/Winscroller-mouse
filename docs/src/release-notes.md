# Release Notes

## v1.0.0
- Initial public release of **Winscroller Mouse** — faithful Rust + DirectComposition Windows clone of `omarchy-plume`.
- 6 GPU trails, 6 halos, 8 color modes, Shake-to-Find, full `14 × 30 × 22 × 18` procedural SVG Cursor Forge with native `.cur`/`.ani` generation, 8-tab Direct2D/DirectWrite Settings Panel, 12 preset looks, 16 preset cursors, 12 saved slots, Named-Pipe CLI IPC, and `~9.7 MB` private memory footprint.
