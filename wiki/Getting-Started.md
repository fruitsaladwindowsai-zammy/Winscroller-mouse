# Getting Started

1. Download `winscroller-mouse.exe` from the [Latest Release](https://github.com/fruitsaladwindowsai-zammy/Winscroller-Mouse/releases/latest) (statically linked, zero dependencies).
2. Double-click `winscroller-mouse.exe` to start in the Windows system tray, or run `winscroller-mouse.exe settings` to open the 8-tab Settings Panel immediately.
3. **Tray Controls**:
   - **Left-click**: Toggle pointer effects
   - **Right-click**: Context menu (Settings, Quick Looks, Ready-Made Cursors, Find, Undo, Restore System Cursor, Quit)
   - **Middle-click**: Trigger Shake-to-Find radar burst
   - **Double-click**: Open Settings Panel
