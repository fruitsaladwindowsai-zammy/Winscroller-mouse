# CLI and IPC Scripting

Winscroller Mouse listens on the local named pipe `\\.\pipe\WinscrollerMouse`:

```powershell
winscroller-mouse.exe settings
winscroller-mouse.exe toggle
winscroller-mouse.exe find
winscroller-mouse.exe look neon
winscroller-mouse.exe nextLook
winscroller-mouse.exe cursor candy
winscroller-mouse.exe cursor default
winscroller-mouse.exe set trail sparks
winscroller-mouse.exe save 1
winscroller-mouse.exe load 1
winscroller-mouse.exe exportLook
winscroller-mouse.exe importLook "{...}"
winscroller-mouse.exe status
winscroller-mouse.exe quit
```
