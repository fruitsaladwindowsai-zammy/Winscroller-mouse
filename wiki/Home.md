# Welcome to the Winscroller Mouse Wiki

**Winscroller Mouse** is a native Windows 10/11 custom cursor forge and GPU-accelerated pointer effects daemon written in pure Rust — bringing every feature of [omarchy-plume](https://github.com/qempexe/omarchy-plume) to Windows with `~9.7 MB` private memory usage and silky-smooth DirectComposition rendering.
